Family Home

The first screen after sign-in, for a student or a parent (same data, the chip at the top switches child). Three answers to "what is Home for?". A is a to-do list for tonight, B is a report on how the child is doing, C puts one thing first with Bookie and shows the rest as small tiles. Flip the state below to see each Home on a different day. Tap homework rows in A to tick them.

The day:
Same for student and parentData is identical. The child chip only matters for a parent with more than one child; for a student it is just their name and class.
What exists todayHomework, attendance (with rank), fees and the exam timetable all have routes. Results, notices and the bell need new work, so they are dashed or labelled "later".
Mix and matchThese parts can move between directions: A's tick rows inside C's card, B's streak stamp in A, C's tile faces in B.
