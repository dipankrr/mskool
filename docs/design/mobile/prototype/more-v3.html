More, v3: a screen for every area

More stops being one page of cards. A pinned bar across the top holds the areas that have no bottom tab: Overview, Exams, Academics, Staff, School. Each one is a real screen built the same way: what is happening, what needs you, four doors, then the list itself. Tap the bar on any phone to switch; scroll a long list and the bar slims down but stays.

Decided with you

  • A dashboard for each area, not the old screens dropped in.
  • Overview opens first: every area at a glance, and everything that needs you in one list.
  • The bar stays pinned. Tap to switch; no swiping (no new native library).
  • The More heading row is gone: no title, no menu button, no avatar. The bar starts under the status bar.

How each area screen is built

  • Hero in the area's colour: the one thing that matters now (the running exam, the term, who is in today).
  • Needs you: only rows with something to do, each with its own button. Gone when all is fine.
  • Four doors: the area's main places and actions. A plus marks an action.
  • The list: exams, classes, people, branches. Deeper screens still push on top, with back.

Choices I made, for you to check

  • The bar slims when you scroll (frame 5): pictures fold, names stay. It is still pinned; say if you want it full size always.
  • Overview each time More opens fresh; inside one session it keeps the area you were on.
  • A teacher gets fewer tabs (Overview, Exams, Teaching). With only one area the bar is not shown.
  • Every tab is a different colour band; the band follows the chosen tab.

Open

  • Sidebar and account popup from More. With the heading row gone, More has no menu button or avatar. Today only Home has them; once the other tabs get them, More is the one tab without. OK, or a small avatar in the Overview hero?
  • Exams, Staff and Academics also exist as pushed screens (from Home cards and the sidebar). Should those links open More on that tab instead, so there is one place per area?
