Teacher homework, v2

Version 2 (2026-11-08), after the owner's review of v1 (homework.html, kept as it was). Give is stepped, like the admission flow, in the same four steps for every type: what (Homework, Practice, Project, Reading, Quiz) → classes, grouped by subject → the work itself → when and how. Each type has defaults for how it comes back (brought to class, sent in the app, student ticks it, nothing) and grading (none, marks, grade, remark: Excellent / Good / Bad); work that comes back to the teacher is always checked on the Done list, and grading adds a score on top. Quizzes have their own place on Home. Reading gets a "who ticked" screen, "Diary" is now "All homework", and the copy says "student" throughout. There are no notifications yet, so nothing here promises one.
