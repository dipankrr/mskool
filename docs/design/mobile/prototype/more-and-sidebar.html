More tab and sidebar

More stops being a list of names. Each entry says its state before you open it, and anything waiting on you rises to the top. Who you are and where you are (branch, session, sign out) moves into a sidebar that opens from the avatar on any tab. Tap the avatar on the first phone to try it.

What changes in More

  • Needs you on top: only things with something pending. Gone when all is fine.
  • Tiles with one live line for the places you visit often.
  • Quiet rows for things set once a year (classes, branches, sessions).
  • Students row removed. It is already a tab.
  • Identity, branch, session, sign out leave for the sidebar.
  • Search appears only past about eight destinations.
  • Every screen that is not a tab has a home here (added 15 Nov, round two): staff leave, family logins, ID cards, timetable, payments, ledger, reports, and one Setup list for attendance, fee and exam rules. The buttons inside each tab stay; this is a second door, not a move.
  • "On web" marks screens the phone does not have yet. "Soon" marks ones not built anywhere.
  • Start-something chips under search: Admit a student, Add staff, New exam.

What the sidebar holds

  • You: name, roles, Profile and access.
  • Branch switcher with one number per branch, so you switch because you saw something.
  • Session, with a clear amber state when viewing a past one.
  • Sign out, with the app version beside it.
  • Bell for notifications (not built yet), Change password, and an App group: notification settings, language, help. None of the App group exists today.
  • No destination list. That stays in More, so the two never compete.
  • Opens from the avatar only. No edge swipe, so Android back and sideways grids keep working.
